# 一碗海风的迁徙 · H5

《出版与数字发布》结业作品配套 H5：一张关于闽粤桂琼四省的美食地图，6 个文化地域、34 道菜，记录百余年来海内外交融中的舌尖变迁。

- 封面 → 目录 → 地图 → 地域 → 菜品，五级页面，一条连续的空间推近
- 手机浏览器打开即为全屏；电脑浏览器打开为居中手机框
- 三段《舌尖上的中国》环境音顺序循环，翻页不中断，右下角可静音
- 34 道菜每道有图片位与家族记忆来稿人署名；20 道附解说音频（其余 14 道暂缺，补齐同名文件即自动出现）

## 文件结构

```
一碗海风的迁徙h5待部署/
├── index.html            H5 本体（HTML/CSS/JS 全部内联，单文件）
├── README.md             本说明
└── assets/
    ├── 图片/             34 张菜品图（ch1-01.jpg … ch6-04.jpg）
    ├── 音频汇总/         20 段菜品解说音频
    └── 音频背景/         背景音乐 bgm-01/02/03.mp3（01→02→03 循环）
```

CSS 与 JavaScript 全部内联在 `index.html` 里，没有单独的 .css / .js 文件——上传时只需 `index.html` 和 `assets/` 两个东西。

本地预览：直接双击 `index.html` 用浏览器打开即可，无需任何环境。

## 部署到 GitHub Pages（全程网页操作，不需要装任何软件）

1. **建仓库**：登录 github.com → 右上角 `+` → `New repository`
   - Repository name 建议用英文小写加连字符，如 `yifan-haifeng-h5`（这个名称会出现在访问网址里）
   - 选 **Public**（免费账号只有公开仓库能开 GitHub Pages）
   - 其余都不勾（不要勾 Add a README，因为要传自己的）→ `Create repository`
2. **上传文件**：创建后的页面点 `uploading an existing file`，把**本文件夹里的内容**（`index.html`、`assets`、`README.md`）一起拖进虚线框——注意拖的是文件夹里面的东西，不是"一碗海风的迁徙h5待部署"这个外层文件夹，这样仓库根目录直接就是 `index.html`。等待全部文件显示出来后点 `Commit changes`（15MB，大约需要几分钟）。
3. **开启 Pages**：仓库页 `Settings` → 左侧 `Pages` → Source 选 `Deploy from a branch`，Branch 选 `main`、`/(root)` → `Save`。
4. **访问**：等 2–10 分钟，Pages 设置页顶部会出现网址：`https://<你的用户名>.github.io/<仓库名>/`。手机、电脑都能打开，把这个链接发给同学即可。

## 注意事项

- **中文路径**：`assets/图片`、`assets/音频汇总` 等中文名称 GitHub 完全支持，浏览器会自动处理，不需要改名。
- **私有仓库**：如果仓库设为 Private，免费账号无法开启 Pages（需要 GitHub Pro）。本作品仅课内交流、链接只发给同学，公开仓库即可；介意的话也可以只把 `index.html + assets` 用其他方式（如压缩包）分发，本地双击同样能看。
- **更新内容**：以后改了文件，进仓库页面点 `Add file → Upload files`，把改过的文件拖进去覆盖同名文件即可。
- **底图口径**：地图页脚标注为「底图：天地图 · 课堂展示」，与目录页「天地图行政区轮廓 · 文化地域示意」一致，全文不出现审图号占位字样；底图为示意用法，仅课堂展示。
- 本包基于 v21（作者与来稿人署名版）生成；交互与内容的完整版变更记录见项目工作区的《H5-需求规格与工作方案.md》。
